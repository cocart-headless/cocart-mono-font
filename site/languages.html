04

How we check

Every release runs the same tests on every font file we ship. {{ checkedText }}

Every character, every styleEach language's letters, capitals, quotation marks and currency sign, in all nine weights, their italics and the variable fonts.
Stays on the gridAccents and vowel marks must not take up a cell of their own, so prices and order numbers still line up in columns.
Nothing gets cut offTall accents and deep descenders must stay inside what Windows will draw, and we note anything that reaches past the default line height on macOS.

Notes for macOS

Nothing is cut off. These marks reach a little past the default line height, so with line-height below 1.25 they can touch the line above or below. Most fonts behave the same way with these letters.
